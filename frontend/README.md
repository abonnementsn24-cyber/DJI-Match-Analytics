# EMDJI Match Analytics — Frontend

Next.js (App Router) + TypeScript + Tailwind CSS. See the [repository
README](../README.md) for the full setup (backend, Docker, variables
d'environnement) and [`docs/`](../docs) for the model/pipeline documentation.

```bash
npm install
cp .env.local.example .env.local
npm run dev
```

```bash
npm run build   # production build + TypeScript check
npx eslint .     # lint
```
